GameKit is a 2D **Java** game engine for creating simple games fast. GameKit is based on
Java [Swing](https://docs.oracle.com/javase/tutorial/uiswing/index.html) hence rendering is CPU based and not GPU based.

GameKit is not a AAA engine and has limitations due to it not using OpenGL, but performance is decent enough for small
to medium-sized games.

Check out the [Getting Started](./tutorials/getting-started.md) guide on how to install and use GameKit.
